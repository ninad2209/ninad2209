## 🔭 How I Think About Security:

```
Every feature I build, I ask:
  ├── 🔑  Who should have access to this?
  ├── 📦  What data am I storing — and do I really need it?
  ├── 🚪  What happens if this input is malicious?
  ├── 🕵️  How would an attacker abuse this endpoint?
  └── 🛡️  Is the user's privacy protected by default?
```
